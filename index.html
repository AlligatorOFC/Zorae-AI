Documentação Oficial do Zorae

Guia completo de arquitetura, rotas, personalidades, memórias e recursos técnicos.

1. Arquitetura Client-Side

Zero Backend e Privacidade

O Zorae opera de forma totalmente autônoma no navegador do usuário. Todas as mensagens, preferências e dados da aplicação são persistidos localmente através de IndexedDB (banco zorae_local_v1) com espelhamento automático e resiliente em LocalStorage.

Configuração de Hospedagem & Rotas

O aplicativo utiliza a History API para gerenciar URLs amigáveis (/, /docs, /updates, /chat/:id). Para hospedagem em serviços de arquivos estáticos (como GitHub Pages, Vercel, Netlify ou Cloudflare Pages), é indispensável configurar um redirecionamento de fallback (SPA Rewrites) para que todas as requisições apontem para index.html.

2. Personalidade Adaptativa Masculina

Comportamento Dinâmico

Por padrão, o Zorae adota uma postura masculina, amigável, inteligente e descontraída em chats casuais. Quando o usuário apresenta demandas formais, técnicas, de programação ou temas sensíveis, o sistema ajusta automaticamente a sua postura para ser profissional e acolhedor.

3. Gestão de Memória Multicamada

Categorização Inteligente

As memórias são organizadas em quatro pilares: Permanentes, Preferências do Usuário, Contexto da Conversa e Temporárias. O Zorae registra automaticamente novos dados na memória apenas quando detecta uma intenção declarativa clara do usuário.

Versão 2.0 (Atual)

Arquitetura Multirotas & UX Reorganizada

• Suporte nativo à navegação por URL com History API (`/docs`, `/updates`, `/chat/:id`).

Lançamento do Protótipo Zorae

• Suporte à API Gemini e pesquisa web Tavily.
• Armazenamento primário no IndexedDB.
